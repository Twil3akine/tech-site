E0382 は、所有権が移った値をもう一度使おうとしたときに発生するコンパイルエラーである。エラーコードの一覧は[公式ドキュメント](https://doc.rust-lang.org/error_codes/E0382.html)で確認できる。最初に、String を別の変数へムーブした後で元の変数を使う例を示す。

これはコンパイルエラーになる。

```rust
fn main() {
    let value = String::from("hello");
    let moved = value;
    println!("{value}");
    assert_eq!(moved, "hello");
}
```

## エラー文を読む

コンパイラは概ね次のような診断を出す。実際の行番号や補足表示は Rust のバージョンや出力設定で異なるが、それぞれの行が示す役割は同じである。

```text
error[E0382]: borrow of moved value: `value`
 --> src/main.rs:4:15
  |
2 |     let value = String::from("hello");
  |         ----- move occurs because `value` has type `String`, which does not implement the `Copy` trait
3 |     let moved = value;
  |                 ----- value moved here
4 |     println!("{value}");
  |               ^^^^^ value borrowed here after move
```

`error[E0382]` はエラーコードと概要である。`-->` は問題のあるファイルと位置、下のラベルは値を作った場所、ムーブした場所、再利用した場所をそれぞれ示す。診断の説明部分には、String が Copy ではないことも表示される。

## なぜ起きるか

String のような値を別の変数へ代入すると、通常は値の所有権が移る。`moved` が所有者になった後、`value` は有効な値を持たないため再利用できない。所有者が一つだけであることで、解放の二重実行を防いでいる。

```rust
fn main() {
    let original = String::from("hello");
    let owner = original;

    // 所有権を受け取った変数からは値を使える
    assert_eq!(owner.len(), 5);
    assert_eq!(owner, "hello");
}
```

## 直し方1: 参照で借りる

関数が値を所有する必要がないなら、参照を渡して借用する。借用なら元の String の所有者は変わらず、呼び出し後も使える。文字列を読むだけの関数では `&str` を受け取る形がよく使われる。

```rust
fn text_length(text: &str) -> usize {
    text.len()
}

fn main() {
    let value = String::from("hello");
    let length = text_length(&value);

    assert_eq!(length, 5);
    assert_eq!(value, "hello");
}
```

## 直し方2: cloneで複製する

二つの独立した String が必要なら `clone` で内容を複製する。複製にはメモリ確保と文字列のコピーが伴うため、所有権を保つためだけに常用するのではなく、別々に変更する必要がある場合などに選ぶ。

```rust
fn main() {
    let value = String::from("hello");
    let copied = value.clone();

    assert_eq!(value, "hello");
    assert_eq!(copied, "hello");
    assert_ne!(value.as_ptr(), copied.as_ptr());
}
```

## 直し方3: Copy型を使う

整数や `bool` など Copy を実装する型では、代入時に値がコピーされるため、元の変数も引き続き使える。String は内容の所有権を管理するので Copy ではない。

```rust
fn main() {
    let count = 7_i32;
    let other = count;

    assert_eq!(count, 7);
    assert_eq!(other, 7);

    let enabled = true;
    let also_enabled = enabled;
    assert_eq!(enabled, also_enabled);
}
```

どの方法を使うかは、関数が値を所有すべきかで決める。読むだけなら参照、独立した値が必要なら clone、小さく Copy な値ならそのまま渡すのが基本である。
