探したいものがファイル名なのか、ファイルの中身なのかで使うコマンドが変わる。名前や更新日時からファイルを探す場合は `find`、ファイルの中の文字列を探す場合は `grep` または `rg` を使う。

以下の例は現在のフォルダを起点にする。対象を広げると出力も増えるため、最初はプロジェクトのフォルダへ移動してから実行する。

## 名前でファイルを探す

`find` の基本形は探す場所、条件、結果に対して行う操作の順で書く。ファイル名で探す場合は `-name` を使う。

```console
$ find . -name "*.rs"
./src/main.rs
./src/lib.rs
```

`-name` は大文字と小文字を区別する。大文字小文字を区別せずに探す場合は `-iname` を使う。

```console
$ find . -iname "readme*"
./README.md
```

パターン全体を引用符で囲むのは、シェルではなく `find` 自身にパターンを渡すためである。引用符を外すと、シェルが先にファイル名へ展開してしまうことがある。

## 種類と更新日時で絞る

ファイルだけを探す場合は `-type f`、フォルダだけを探す場合は `-type d` を付ける。

```console
$ find . -type f -name "*.md"
$ find . -type d -name "tests"
```

更新日時は `-mtime` で指定できる。`-mtime -7` は、過去7日以内に更新されたファイルを表す。

```console
$ find . -type f -mtime -7
```

`+7` にすると7日より前に更新されたファイル、`7` だけだとちょうど7日前に更新されたファイルを対象にする。単位は日であり、時刻まで細かく指定したい場合は `-mmin` を使う。

## ファイルの中身をgrepで探す

`grep` はファイルの中から、パターンに一致する行を表示する。再帰検索には `-R`、行番号には `-n` を付ける。

```console
$ grep -Rn "fn main" .
./src/main.rs:3:fn main() {
```

大文字と小文字を区別しない場合は `-i`、対象ファイルを絞る場合は `--include` を使う。

```console
$ grep -Rni --include="*.rs" "todo" .
```

検索結果が多すぎる場合は、対象フォルダを `src` や `tests` に限定する。二進数ファイルや `.git` の内部まで読むと見づらくなるため、プロジェクト全体ではなく、必要な範囲から始める。

## rgでプロジェクト内を検索する

[ripgrep](https://github.com/BurntSushi/ripgrep) は、コマンド名 `rg` で使う検索ツールである。プロジェクト内の検索を主な用途とし、通常は `.gitignore` の対象や隠しファイルを自動で避ける。インストールされていない環境もあるため、`find` と `grep` の基本も使えるようにしておく。

```console
$ rg "fn main"
$ rg -n "TODO|FIXME"
$ rg "struct User" src
```

主なオプションは次の通りである。

- `-n`: 行番号を表示する。`rg` は対話的な表示では行番号を付けることが多いが、明示すると結果を共有しやすい
- `-i`: 大文字と小文字を区別しない
- `-w`: 単語単位で一致させる
- `-g "*.rs"`: 対象のファイルパターンを指定する
- `--hidden`: 隠しファイルも対象にする
- `--no-ignore`: `.gitignore` などで除外されたファイルも対象にする

通常の `rg` で見つからないファイルがある場合は、無視規則の対象になっている可能性がある。ただし、`--hidden` と `--no-ignore` を常に付けると、依存関係や生成ファイルまで大量に含まれるため、見つからない理由がある場合だけ使う。

## 探したファイルに対して処理する

`find` の結果に対してコマンドを実行するには `-exec` を使う。`{} +` の位置に、見つかったファイルがまとめて渡される。

```console
$ find . -type f -name "*.log" -exec wc -l {} +
```

削除のように取り返しのつかない操作を組み合わせる場合は、先に同じ条件で一覧だけを表示し、対象を確認する。検索条件を再利用するときも、まず出力を見て対象が絞れているかを確かめる。

## 使い分け

- ファイル名、種類、更新日時で探す: `find`
- 1つのファイルや単純な範囲を文字列で探す: `grep`
- プロジェクト全体を日常的に検索する: `rg`

コマンドを覚える順序はまず探す範囲を決めることである。範囲が広すぎると、検索結果が多くなるだけでなく、関係のないファイルまで処理対象になりやすい。
