Python と Rust のコードを並べて比べながら進める、移行する人を強く意識した入門書である。正式な書名は『手を動かして考えればよくわかる 高効率言語 Rust 書きかた・作りかた』。

全6章と Appendix、560頁。前半は小さな題材を Python と Rust の両方で書き、文法編を挟んで、画像・音声・ネットワークの題材とメモリ管理や他言語連携へ進む。書誌情報と目次は出版社（ソシム）の[公式ページ](https://www.socym.co.jp/book/1351)で確認した。クジラ飛行机・著、2022年1月21日発売、定価3,799円（税込）。

## 目次・内容

全6章の構成は次のとおりである。

- Chapter 1 PythonからRustへ準備体操
- Chapter 2 Rustで簡単ツール作成編
- Chapter 3 文法編（所有権システムとデータ型について）
- Chapter 4 文法編（メソッド・ジェネリクス・トレイトについて）
- Chapter 5 画像/音声/ネットワーク
- Chapter 6 応用編（メモリ管理と他言語連携）

Chapter 1 では FizzBuzz や九九、フィボナッチ数列といった小題材を Python と Rust で書き比べ、両言語の違いを先に押さえる。Chapter 2 は Cargo の使い方から標準入力、ファイルの読み書き、再帰検索ツールまで、題材は小さな道具作りが中心である。文法編の Chapter 3、4 で所有権、借用、文字列、トレイト、ジェネリクスをまとめて扱い、Chapter 5 では画像処理、波形合成による音楽、メッセージングアプリ、Webアプリへ進む。Chapter 6 はマクロ、単方向リストによるメモリ管理、C言語や Python との連携、WebAssembly、非同期通信とスクレイピングを扱う。Appendix にはエラーメッセージと解決のヒント、用語集、基本構文のまとめがあり、ダウンロードファイルに同梱される。全サンプルプログラムは著者の GitHub リポジトリで公開されている。

## 注意点 / こんな人にはオススメできない

### Python の経験が前提の進み方

比較の軸が Python なので、Python を書いたことがないと、併記の効果が薄くなる。Rust が最初の言語という人には、比較対象のない分だけ回り道になる。

### 文法の整理は中盤にまとまっている

文法編は Chapter 3、4 に置かれ、前半は題材を先に進める構成である。文法を最初から順序立てて固めたい人には、進み方が合わない場合がある。

### 題材が広いぶん、各分野は入口まで

画像、音声、ネットワーク、WebAssembly と守備範囲が広いため、特定分野を深く進める段階では分野ごとの資料が要る。

## 良い点 / こんな人にオススメしたい

### Python との併記で移行のつまずきを先回りできる

多くの題材で Python 版と Rust 版が並び、書き方の違いがその場で比べられる。エラーを出すコードと出さないコードを比べる示し方もあり、所有権まわりの失敗パターンに早い段階で触れられる。

### 小さな題材の数が多い

FizzBuzz のような小題材から、辞書ツール、画像処理、メッセージングアプリまで、1テーマごとに動くものが手に入る。読むだけの時間が長くなりにくい。

### サンプルと Appendix が学習を助ける

全サンプルが GitHub で公開され、手元で動かしながら読み進められる。Appendix のエラーメッセージ集は、詰まったときに引く用途で本文と分けて使える。

## 類書との比較

### 『実践Rustプログラミング入門 第2版』

同じく作りながら学ぶ実践型だが、あちらは Webアプリケーション、WebAssembly、Tauri、組み込みと用途別の題材が軸である。本書は Python からの移行と比較が軸で、題材はより小粒で数が多い。Python から来るなら本書、用途から探るなら『実践Rustプログラミング入門 第2版』が向く。

- 関連記事: [『実践Rustプログラミング入門 第2版』は作りながら学ぶ実践型の入門書](/books/jissen-rust-2e/)

### 『ゼロから学ぶRust』

正規表現エンジン、シェル、デバッガを実装する入門書で、題材は低レイヤに寄り、線形型システムの理論まで進む。本書の題材は日常の道具作りに近く、理論よりも書き方の習得に寄っている。仕組みを深く知りたいなら『ゼロから学ぶRust』、手を動かして書き方を身につけたいなら本書である。

- 関連記事: [『ゼロから学ぶRust』はシステムプログラミングを実装で学ぶ入門書](/books/zero-kara-manabu-rust/)

## まとめ

Python を書いてきた人が Rust に移るための入門書として、位置づけがはっきりした一冊である。比較しながら小さな題材を多くこなす進み方が合う人には、文法書でつまずく前に書き方を身につける道筋になる。
