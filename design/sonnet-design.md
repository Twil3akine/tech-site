# Twil3akine / Rust 攻略ノート トップページ デザイン仕様

## 1. コンセプト
紙の攻略本の「目次・章番号・難易度表示」を、落ち着いた配色で Web に移す。RPG 風の装飾は使わない。ステージ番号とチェック欄、「最初に読む」の導線で完全ガイド感を出す。書き手の顔（青髪アバター）を一箇所だけ見せて、個人サイトの親しみを担保する。
「完全」は現状の記事数に対して言い過ぎになる。ヒーローでは「完全攻略を目指して更新中・現在 N 記事」と書き、記事数はビルド時に自動で入れる。

## 2. カラーパレット
Rust 公式色 #DEA584 は明るすぎて文字や線に使えない。面の色と下線マーカーに回し、実際のアクセントはそれを暗くした銅色にする。Ferris の鮮やかなオレンジは使わない。

| 役割 | hex |
|---|---|
| 背景（紙） | #FAF6EF |
| カード面 | #FFFFFF |
| 本文 | #1F2433 |
| 補助文字 | #5B6275 |
| 罫線 | #E4DCCD |
| 主色（アバターの青髪由来） | #2E4A8C |
| 主色・濃（ホバー） | #1E2F5C |
| アクセント（銅） | #B7552B |
| Rust 色の面・マーカー | #DEA584（淡色 #F6E6DA） |
| ステージ1 std | #2E4A8C |
| ステージ2 クレート | #2F7D6B |
| ステージ3 エラー解決 | #C2412D |

- 文字色はいずれも背景 #FAF6EF 上でコントラスト比 4.5 以上を想定している。実装時に確認すること。
- #DEA584 は文字色に使わない。
- セクション色は、カードの上辺、記事行の左バー、チップにだけ使う。

## 3. レイアウト構成
全体は幅 `max-width: 1040px`、左右 padding 24px（SP は 16px）。960px 以上で本文 1fr ＋ サイドバー 256px（gap 40px）の 2 カラムにし、未満は 1 カラムでサイドバーを本文の下に回す。

1. **ヘッダー**（高さ 56px、下罫線 1px）
   - 左に円形アバター 32px と「Twil3akine」（Zen Kaku 700 / 18px）。
   - 右にナビ 3 つ（std / クレート / エラー解決）、各 14px。
   - 書籍レビューへのリンクは置かない。
2. **ヒーロー**（上下 padding 56px / 40px）
   - 小ラベル「RUST 攻略ノート」（12px、銅色、letter-spacing .14em）。
   - H1「Rust を、ひとつずつ攻略する。」
   - リード文 1〜2 行と、現在の記事数。
   - ボタン 2 つ：主「最初に読む」、副「エラーから探す」。
   - 右側にアバター（高さ 160px）と吹き出し「迷ったらここから！」を置く。SP では非表示。
   - 背景に方眼（24px 間隔、線 #EFE7D8）を敷く。ヒーロー内だけで、ノートという意味がある範囲に限る。
3. **ステージ導線**：3 枚のカードを横並びにする（SP は縦積み）。
   - 内容は「STAGE 01」、セクション名、1 行説明、記事数。
   - ステージ 3 は説明を「詰まったらここ」にして、順番に読む章ではなく辞書的な位置づけだと分かるようにする。
4. **記事リスト**（H2「新着記事」）
   - 新しい順に 10 件。
   - 末尾に「すべての記事を見る」リンクを置く。
5. **サイドバー**（カード面、枠 1px）
   - 「はじめての人へ」：推奨順 3 本の番号付きリスト。
   - 「読了チェック」：読んだ記事数と全体の比（例 2 / 4）を、細いバーで出す。
   - 「タグ」：上位 12 個。
6. **フッター**：上罫線、文字 13px、補助色。内容は © Twil3akine、プライバシーポリシー、GitHub リンク。

## 5. 攻略サイトらしさの仕掛け
採用するもの：
- **ステージ番号**：STAGE 01〜03 のモノスペースラベル。
- **難易度ドット**：●○○（入門）／●●○（基本）／●●●（応用）。記事 front matter に `extra.level = 1..3` を追加する。
- **読了チェック**：記事ページを開いたら localStorage に保存し、リストに ✓ を出す。外部送信はせず、JS は 20 行程度。JS が無効でも一覧は壊れない。
- **「最初に読む」**：推奨順を先頭に固定する。
- **吹き出し付きアバター**：トップのみ。記事ページには出さない。

線引き：経験値・レベル・バッジ・実績解除は入れない。進捗は「N / 全体」の数字とバー 1 本までにする。

## 6. コンポーネント仕様
- **記事行**
  - 縦 padding 16px、下罫線 1px #E4DCCD。
  - 並びは、難易度ドット、タイトル（17px / 700）、チップ、日付（13px）の順。SP ではタイトルの下にメタを折り返す。
  - ホバーは背景 #FFF、左に 3px のセクション色バー、タイトルに銅色の下線（太さ 2px、offset 4px）。transition は .15s。
- **ステージカード**
  - 白背景、枠 1px #E4DCCD、角丸 6px、上辺 4px にセクション色、padding 20px。
  - ホバーは `translateY(-2px)` と `box-shadow: 3px 3px 0 #E4DCCD`。影のぼかしは使わない。
- **タグ**：12px、padding 2px 8px、角丸 4px、枠 1px #E4DCCD、文字は補助色。ホバーで背景 #F6E6DA、枠 #DEA584。
- **セクションチップ**：タグと同形で、文字と枠をセクション色にする。
- **ボタン**
  - 共通は padding 12px 20px、角丸 6px、14px / 700、高さ 44px 以上。
  - 主は背景 #2E4A8C、文字白。ホバーで #1E2F5C。
  - 副は透明背景、枠 1px #2E4A8C、文字 #2E4A8C。ホバーで背景 #EEF1F8。
  - フォーカスは 2px の銅色アウトライン、offset 2px。
- **進捗バー**：高さ 6px、角丸 3px、地は #E4DCCD、塗りは #B7552B。

## 7. やらないこと
- ピクセルフォント、RPG 風ウィンドウ枠、ネオン色、ドット絵。
- Ferris や Rust 公式ロゴの流用、他の有名サイトに似せた配置。
- 記事数に見合わない「完全」「全部」の断言。
- XP・レベル・実績などのゲーム化、ポップアップやバナー広告。
- 書籍レビューへの導線。
- 意味のない罫線や装飾。方眼はヒーロー 1 箇所のみ。
- 1 画面に 4 色を超えるアクセント色を同時に出すこと（セクション色は各カード内で完結させる）。
- ダークモード（今回の範囲外。必要なら別途設計する）。
