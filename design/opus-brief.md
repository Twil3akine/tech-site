# 解説サイト デザインリサーチメモ（2026-11-10、Alis）

対象: Zenn / MDN / Stripe Docs / Tailwind CSS / Rust 公式 Book / Progate のトップ画面の構成と公開 CSS・ページ構造から読み取れる範囲。

## 各サイトの第一画面の型

- **Zenn**: 白背景。ヘッダーはロゴ＋検索＋ナビのみで細い。コンテンツは「イベントバナー→Tech（記事カード）→Ideas→Books→Topics→新着」のセクション見出し＋カードグリッド。カードは白地に薄い枠と小さな角丸、絵文字アイコン。青（#3EA8FF 系）が唯一のアクセント。余白が広く、罫線は最小限。
- **MDN**: 白背景、黒文字、青リンク。大きな検索窓が主役のヒーロー（グラデーション帯）。見出しは太く大きく、カードは薄グレー面＋角丸。装飾はほぼ色面だけ。
- **Stripe Docs**: 白〜ごく薄いグレーの面、スレート系文字、紫〜青のグラデーションを一点だけ使う。フォントは独自サンセリフで見出しの字間が詰まっている。枠線より面の重なりと影で階層を作る。
- **Tailwind CSS**: ダーク（slate-900）のヒーローに大きな見出し（48px 級、太字、字間 tight）、sky 色アクセント1色。コード断片をそのまま見せる。余白が非常に大きく、要素数が少ない。
- **Rust 公式 Book**: マーケティング要素ゼロ。左に目次サイドバー、本文は最大幅 750px、等幅は Source Code Pro。色はテーマ変数のみで極めて抑制的。「解説サイトの本文ページ」の標準形。
- **Progate**: 明るいイラストと原色に近い青・緑、角丸の大きいカード、丸みのあるフォント。親しみは「色と図版」で出し、レイアウト自体は今どきのグリッド。

## 共通項（=「ダサくない」側の条件）

1. 背景は白か、それに近い単色。テクスチャ（紙・方眼）は使わない。
2. アクセント色は実質1色（+意味色のセクション色は面ではなく小さなラベルに限定）。
3. 見出しが大きい（32〜56px）し字間が詰まっている。本文とのサイズ比が大きい。
4. 罫線で区切らず、余白と面で区切る。カードを使う場合も枠は薄く、影は柔らかく浅い（ハードシャドウ 3px 3px 0 のようなオフセット影は使わない）。
5. 角丸は 8〜16px が標準。6px 以下の小さな角丸＋実線枠の組み合わせは古く見える。
6. フォントはサンセリフ1系統で統一し、ウェイト差で階層を作る。
7. 第一画面の要素が少ない。ヒーローは「一文＋検索 or 主要導線1〜2個」まで。

## 現行「Rust 攻略ノート」案がダサく見えた要因（オーナー判定: ダサい・出すのが恥ずかしい）

- 紙色背景 #FAF6EF＋方眼＋銅色＋茶系の補助色という組み合わせが、2000年代の個人サイト／紙の攻略本の懐古調になった。
- 全要素に 1px 実線枠＋小さな角丸（6px）＋ハードシャドウで、部品感が強い。
- 見出しが小さく（H1 40px はあるが画面密度が高く）、余白より情報量が勝っている。
- セクション色3色＋銅＋青と、色数が多い。
- 「STAGE」「難易度ドット」などの記号は悪くないが、受け皿の意匠が古いため記号まで古く見えた。

## 次のデザインへの要求

- 上の共通項を満たす、今どきの開発者向けドキュメント／学習サイトの水準で設計する。
- 「完全 Rust 攻略」という看板の頼もしさは、装飾ではなく「情報設計（網羅の見せ方・導線・進捗）」で出す。
- 書籍レビューはトップに出さない。検索はヘッダーに置く。アバターは使ってもよいが必須ではない。
